# Day 7：生成答案审核规则 v2

这是教学用的自定义 0～2 分审核标准，不是 RAGAS 官方计算公式。三个维度分别记录，不直接合成答案准确率。

审核输入：问题、题面前提、实际提供给生成模型的片段、模型回答，以及参考答案。正确性可以使用参考答案；忠实度必须依据实际提供的片段和题面前提，不能把参考答案或裁判自己的知识当成检索证据。

## 正确性 correctness

- 2：核心结论及题目要求的事实正确、完整，适用对象和前提一致。
- 1：部分事实正确，但遗漏题目要求的关键事实、条件或存在部分错误。
- 0：核心结论错误、答错对象，或没有提供可回答题所需的答案。

合理同义表达不扣分；不要求逐字匹配参考答案。资料不足题正确说明无法从当前材料确定答案可记 2 分；编造具体结论记 0 分。

## 忠实度 faithfulness

- 2：回答中的事实陈述及推理均由实际片段和题面前提支持。
- 1：既有支持的陈述，也有无依据或与当前片段不一致的陈述。
- 0：核心事实没有当前资料支持，或与当前资料相矛盾。

允许由已提供规则进行有效推理，必须能指出规则来源。缺少某个预先标注的片段并不自动意味着回答不忠实；要检查回答实际说了什么。

如果回答仅拒答：实际片段确实不能支持答案，则此教学规则将合理拒答记 2；实际片段已明确提供答案但仍称资料未说明，则记 0。这是本审核标准的约定，不是通用的基于事实断言数量的忠实度公式。

## 相关性 relevance

- 2：直接回应当前问题，紧扣用户询问的对象与任务。
- 1：回应了部分问题，或夹杂明显无关内容。
- 0：回答其他对象/其他问题，没有回应当前任务。

相关不等于正确：针对同一问题给出的错误数值仍可能是相关回答。不要把正确性和忠实度的低分机械复制到相关性。

仅针对当前问题作出拒答（例如“资料未说明”），相关性记 2，不因没有给出具体答案而扣相关性分。拒答是否合理由正确性和忠实度判断：资料已明确有答案却拒答，可以是正确性 0、忠实度 0、相关性 2。拒答如果转向其他问题或夹杂无关内容，仍按上述相关性规则判断。

此拒答边界经用户确认。它不表示所有样例的预设分数已经经过用户逐条审核。

## 评分记录

每个维度记录整数得分及理由；得分必须为 0、1、2，布尔值不是合法得分。忠实度理由引用实际资料编号或指出未支持的具体陈述。

审核状态区分 `pending_review`、助手审核、用户人工审核和 LLM 裁判审核，不能相互冒充。接口失败、空输出、截断或非法评分应记为评分失败，不记 0 分，也不能默默当成成功。

简单的数学、编号范围与单位判断可以用规则核对；语义判断先用少量人工样例校准。模型裁判也会判断错误，同一模型既生成又评分可能存在偏好，需要独立人工校准后才能解释大规模结果。

## 教学反例

问题：Bucket ACL 默认是什么？
实际片段 [1]：Bucket ACL 的默认权限值是 private。
实际片段 [2]：Object ACL 的默认值是 default，表示继承所属 Bucket 的 ACL。

- 回答“Bucket 默认 private。[1]”：正确性 2、忠实度 2、相关性 2。
- 回答“Object ACL 默认 default。[2]”：正确性 0（答错对象）、忠实度 2（片段支持）、相关性 0（没有回答 Bucket 问题）。

反例为人工编写的教学材料，不是模型真实输出。真实待审核响应另见 data/eval_results/day7_answers_sample.json；本文件没有将三道真实题自动记为通过。
